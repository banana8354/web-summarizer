# 技术说明

面向使用者的简要说明，帮助理解本项目如何工作、能做什么、不能做什么。

## 这是什么

「网页总结工具」是一个本地运行的小应用：你输入一个网址，服务端去抓取该网页的 HTML，抽出正文文字，再用**抽取式摘要**挑出最重要的几句话展示给你。

全程不调用任何大模型 API，也不需要 API Key，只要本机装了 Node.js 18+ 即可。

## 技术栈

| 部分 | 选型 | 原因 |
|------|------|------|
| 后端 | Node.js 内置 `http` / `fs` / `path` + 全局 `fetch` | 零第三方依赖，`node server.js` 即可启动 |
| 正文提取 | 正则剥离脚本/样式/导航等标签 | 轻量、无 cheerio 等解析库 |
| 摘要 | 词频打分的抽取式算法 | 离线可用、结果可解释 |
| 前端 | 原生 HTML / CSS / JS | 无构建步骤、无 CDN |

## 摘要算法（简述）

1. 去掉 `<script>`、`<style>`、`<nav>`、`<footer>` 等噪声区域。
2. 去掉 HTML 标签并解码常见实体，得到纯文本。
3. 按中英文标点切成句子。
4. 统计词频（过滤停用词），按词频给句子打分，并略微提高靠前句子的权重。
5. 取分数最高的 3–4 句，按原文顺序输出。

这是「从原文挑句子」，不是「用 AI 重新写一段话」。因此摘要会保留原文措辞，也可能漏掉需要语义理解才能抓住的要点。

## 接口

- `GET /` → 返回前端页面
- `GET /api/summarize?url=<网页地址>` → JSON

成功示例：

```json
{
  "ok": true,
  "title": "页面标题",
  "url": "https://example.com/...",
  "summary": ["句子一", "句子二", "句子三"],
  "chars": 1234
}
```

失败时 `ok` 为 `false`，`error` 为人话错误说明。`url` 必须以 `http://` 或 `https://` 开头。

## 已知限制

- **动态渲染站点**：若正文主要由前端 JS 渲染，服务端拿到的 HTML 可能几乎没有正文。
- **反爬 / 登录墙**：部分站点会拦截非浏览器请求，或需要登录后才能看全文。
- **非中文/英文混排复杂页面**：分句与停用词偏向中英文，其他语言效果可能一般。
- **抓取超时**：单次请求最长约 15 秒。
- **版权与合规**：请只总结你有权访问的公开页面，并遵守目标站点的使用条款。
